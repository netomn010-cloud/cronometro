# ⏱️ Cronômetro

Cronômetro funcional e interativo desenvolvido para praticar **HTML, CSS e JavaScript**.

## 🚀 Funcionalidades

- ▶️ Iniciar
- ⏸️ Pausar
- 🔄 Reiniciar
- ⏱️ Contagem de tempo em tempo real

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Projeto desenvolvido durante meus estudos de **Análise e Desenvolvimento de Sistemas**, com o objetivo de praticar programação e desenvolvimento web.
